# Designing documentation for accessibility

[Read the article](https://sites.google.com/view/designingdocumentationforacces/home){ .md-button target="_blank" }

## What the article covers

- What accessible documentation is, and who it serves
- Why technical writers should care: reach, trust, fewer support requests, and legal and ethical expectations
- Practical techniques: plain language, nested headings, alt text, table header rows, descriptive link text, captions and transcripts, readable fonts and contrast
- How to test documentation with free checkers
- How accessibility skills add to a writer's value
