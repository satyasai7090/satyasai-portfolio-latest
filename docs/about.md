# About Satya Sai Pasupuleti

I'm a Senior Technical Writer at Redwood Software, where I document RunMyJobs, an enterprise workload automation and job scheduling platform, and JSCAPE MFT, a managed file transfer platform. I have six years of experience writing documentation for complex enterprise software in aerospace, life sciences, mainframe data integration and SaaS workload automation, where precision matters.

I take documentation from planning to delivery. I map the information architecture first, write for the person doing the task, and work closely with product managers, engineers, QA and support throughout the development cycle.

## What I write

- **User and administrator guides:** installation, configuration and day-to-day tasks for enterprise products.
- **API and integration documentation:** endpoints, authentication, request and response examples, and webhooks.
- **Release notes:** what changed, why it matters and what to do before and after an upgrade.
- **Knowledge base and troubleshooting content:** organized by symptom, with the cause and the fix.
- **Regulatory and compliance content:** documentation that has to be exact, such as drug safety reporting.

## How I work

I start with the user's task and the product's information architecture, then author structured, single-source content in MadCap Flare and Oxygen XML with DITA, using snippets, variables and conditions for reuse. I write to the Microsoft Writing Style Guide, test procedures against the product, and review with engineering, product and QA inside each sprint. Every product version lives on its own Git branch, and I automate what repeats, like [building and publishing 10–15 versions from a single command](case-studies/rmj-publishing-pipeline.md).
