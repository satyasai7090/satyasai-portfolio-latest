How I work

I start with the user's task and the product's information architecture, then author structured, single-source content in MadCap Flare and Oxygen XML with DITA, using snippets, variables and conditions for reuse. I write to the Microsoft Writing Style Guide, test procedures against the product, and review with engineering, product and QA inside each sprint. Every product version lives on its own Git branch, and I automate what repeats, like building and publishing 10–15 versions from a single command.
